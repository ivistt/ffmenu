# Cadillac ATS 2014 / ориентир GM 20907953

Предварительная модель для примерки по двум перспективным фотографиям.
Это не точная копия OEM и не готовая к установке запасная часть.

## Размеры и допущения

- 620,8 мм — общая длина по прямой между крайними точками X, по данным пользователя. Длина по дуге будет больше.
- 95,5 мм — максимальная ширина по Y, по данным пользователя. Принято, что это ширина корпуса, а не упаковки.
- Стенка 2,5 мм по Z — допущение; толщина по нормали к наклонной поверхности немного меньше.
- Продольный прогиб 35 мм и глубина поперечного профиля 14 мм — условные значения, не измеренные по оригиналу.
- Общая глубина около 50,96 мм, включая стенку и изгиб. Размеры упаковки при построении не использовались.
- Симметрия, сужение концов и гранёный профиль приблизительны.
- Крепления, внутренние рёбра, защёлки, возвратные бортики и надпись Cadillac не восстановлены. Фотографии не задают их размеры и точные координаты.

## Файлы

- `ats_20907953_APPROX_full.stl` — цельная оболочка, единицы при импорте в слайсер: миллиметры, масштаб 100%.
- `fit_section_1_of_4.stl` … `fit_section_4_of_4.stl` — четыре последовательных участка по 155,2 мм. Каждый отдельно отцентрирован по X и опущен до Z=0. Нумерация идёт от отрицательного X к положительному X исходной модели, не обозначает сторону автомобиля.
- Участки предназначены для проверки формы. Штифтов, замков, зазоров для склейки и припуска на шов нет; это не комплект окончательной сборки.
- `generate.py` — редактируемый параметрический исходник без внешних зависимостей. Измените словарь PARAMETERS и выполните `python3 generate.py`.
- `ats_20907953_APPROX.scad` — сеточная модель для OpenSCAD; параметры изменяются в Python с последующей генерацией, а не в этом файле.
- `preview.png` — вид полученной геометрии.
- `validation.json` — размеры, объёмы и результаты проверки замкнутости и ориентации граней. Физическая посадка и печать не проверялись.

## Примерка

Сначала распечатайте один центральный и один крайний участок. В слайсере проверьте ориентацию и поддержки: положение Z=0 не гарантирует плоского контакта всей детали со столом. Не масштабируйте автоматически под стол.

Приложите шаблоны к посадочному месту и зафиксируйте зазоры, ширину площадки, прогиб относительно прямой линии между концами и положения отверстий бампера. Для следующей версии нужны фотографии посадочного места прямо спереди и сверху с линейкой, а также размеры креплений. По ним можно уточнить профиль и построить крепления. Текущая модель не рассчитана на фиксацию на автомобиле.
